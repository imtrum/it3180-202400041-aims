# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-11-05

### Added
- Added discount functionality to the shopping cart.
- Added support for Vietnamese messages.
- Added a use case diagram.

### Fixed
- Fixed an off-by-one error in the cart item limit.
- Improved handling of empty shopping carts.

### Changed
- Improved the cart display by using `cart.print_cart()` instead of calling `print()` directly.
