# Use Case: Search DVD by Title

## Actor
Customer

## Preconditions
- The application is running.
- DVDs are available in the system.

## Main Flow
1. Customer selects the search function.
2. Customer enters a DVD title.
3. System searches for matching DVDs.
4. System displays the results.

## Alternative Flow
- If no DVD matches, the system displays "No results found".

## Postconditions
- Search results are displayed to the customer.
